# Memory Boba 🧋

A simple brain game where you memorize flashing patterns on a grid and tap them back from memory. Every level gets bigger and harder.

## Game Modes
- **Classic**: Level progression from 3x3 to 5x5 grids. 3 strikes and game over!
- **Casual**: Relaxed memory training with no timers and unlimited lives.
- **Speed Classic**: Fast flashes and 5 seconds per round for quick reflexes.
- **Speed Custom**: Fully customize your grid size, target pearl count, and flash duration.
